# September 2026 funding and BER update

The public root now opens a company landing page. Start opens login (existing sessions continue to the interview). Preview login is explicit; production remains invitation-only. The workspace has a dedicated “Grants & what you pay” page.

## Cost evidence

`server/costs.js` transcribes the SEAI PDFs linked from the two requested pages, checked 10 September 2026. Individual costs cover 47,067 measures completed January–December 2025; OSS data covers 1,406 private homes in that period. Apartment external-wall data has only six applications.

Individual measures use dwelling-type medians, without floor-area scaling. A later 11 September refinement removed the earlier ±20% bands, prototype allowances and automatic contingency. Unmatched surveys, repairs, ventilation and optimisation now display **Quote required** and remain outside explicitly partial subtotals. VAT, scope, exclusions and contingency must be confirmed in quotations. Historical PDF grant columns are not used as current grant rates.

OSS works, grants and homeowner costs are independent published medians, retained exactly; they are not calculated by subtracting one median from another. They describe historical whole projects, not the selected individual-measure bundle. No OSS quotation or predicted BER is generated.

Current individual-grant modelling is deliberately conservative: heat-pump system grant only; bonus and central-heating grants need confirmation of eligibility and separately priced works. Enhanced attic/cavity rates and supplementary wall grants are flagged for review. Unknown grant history withholds estimates rather than declaring the homeowner ineligible. Costs and possible grants never guarantee an award. Each measure's contribution is floored at zero before project totals, so surplus hypothetical support cannot subsidise unrelated work.

## Funding and privacy

Fully funded screening gathers owner-occupation, qualifying-payment category, conditional criteria and apartment permissions. It never promises that a homeowner's chosen pathway is free: SEAI decides both eligibility and suitable works. Raw payment selections are excluded from AI profile input and PDF output; the saved PDF contains the screening outcome. Payment details remain in the governed profile, subject to existing access controls, deletion and retention. Do not put welfare details in free-text AI messages.

New OSS, fully funded and cost summaries enter the existing timestamped source library and embedding pipeline. They are manually reviewed summaries, not claimed successful scrapes. The PDF numeric dataset is maintained in code with direct source links; automated PDF extraction/update is not implemented. Source refresh failures retain prior evidence and changed sources require review. Live embedding requires the OpenAI key; Cloud SQL pgvector remains the production adapter.

## BER adapter boundary

`server/ber.js` holds three synthetic fixtures. The authenticated, profile-authorised lookup accepts only 00000000001, 00000000002 and 00000000003. It makes no network request. The user previews results, reviews dwelling fields, then saves through the existing revision-protected profile update. Fixture references and synthetic provenance persist into reports; changing fixture-derived fields detaches a conflicting record. Fixture data never establishes verified heat-loss suitability. Actual BER certificates/advisory reports are not downloaded or OCR-extracted.

Apartment attic recommendations require both access and confirmation that the apartment is top-floor or loses heat through an exposed roof. Management consent remains a separate grant gate. Raw welfare answers are excluded from the stored report snapshot as well as from visible PDF content and AI profile input.

A future authorised SEAI API/document provider should replace this adapter, preserve provider/date/document provenance, confirm homeowner authority and minimise identifiers. Any OCR output needs confidence and user/assessor review before becoming planning facts. No public API access is presumed.
